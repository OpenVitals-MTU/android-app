# OpenVitals 2.10.1

Released 2026-09-26.

This release puts a goal ring on each day of the Month view, so one look at the month shows which days reached the goal and how close the others came. It also stops the dashboard from shuffling its tiles on every refresh when "Sort empty tiles last" is on.

### Added

- **A goal ring on each day of the month.** In a metric's Month view, each day has a thin ring around its number. It fills clockwise from the top with the day's share of the daily goal: 7,500 steps against a 10,000 goal fills three quarters, and a day on or past the goal is full. Steps, distance, calories, active calories, floors, elevation, wheelchair pushes, workouts, hydration, mindfulness and sleep each use their own daily goal. Days with no data and future days get no ring. Nutrition has none yet: its "at most" goals need a different reading. Based on a contribution by Teccheck.

### Changed

- **Libraries.** The Health Connect library moves to 1.2.0-alpha06, and the other libraries the app is built on are updated. Nothing changes on screen.
- **Translations.** Spanish updates contributed by gallegonovato on Codeberg Translate.

### Fixed

- **Dashboard tiles no longer shuffle on refresh.** With "Sort empty tiles last" on, a refresh marked every tile as loading, so the empty tiles jumped back to their saved places and then sank again once the data arrived. A loading tile is not empty: it now keeps its place, and moves only when its own data arrives and changes whether it is empty. On the first load after the app starts, the dashboard still waits for every tile and then sorts once.

The app keeps the same package name and signing certificate, so this installs as a normal update.

Distribution flow:

- Codeberg release with signed APK, signed debug APK, and signed Android App Bundle assets.
- Direct Google Play production upload from the approved Woodpecker deployment.

# OpenVitals 2.14.5

Released 2026-10-18.

This release lets a large Apple Health import run to the end. Health Connect refuses some values outright, such as a basal metabolic rate above 10,000 kcal a day, and one such sample anywhere in an export stopped the whole import with an error, however far it had got. That sample is now left out and listed in the import report, and the import carries on.

### Fixed

- **An Apple Health import that stopped on one value.** A single sample Health Connect cannot store stopped the import with an error. The case reported was an app that logged a whole day's basal metabolic rate as a one-hour sample, which reads as more than 35,000 kcal a day. Such a sample is now counted as failed, with the reason in the import report, and the import carries on. The same goes for any other measurement or logged meal outside what Health Connect accepts, and for a systolic blood pressure above 200 mmHg. Importing the same file again with the same categories picks up where the import stopped, and records already imported are not written twice.

The app keeps the same package name and signing certificate, so this installs as a normal update.

Distribution flow:

- GitHub release with signed APK, signed debug APK, and signed Android App Bundle assets.
- Google Play update to follow, once 2.13.0 has cleared Play review.

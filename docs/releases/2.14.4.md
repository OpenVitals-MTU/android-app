# OpenVitals 2.14.4

Released 2026-10-18.

This release makes a workout's FIT export carry the whole workout. The FIT and TCX files held heart rate and the session totals and nothing else, so a ride opened in a FIT viewer showed a heart-rate line. They now carry the speed and cadence the workout screen shows, and a workout with a GPS route can be saved as a FIT with the route in it. Routes imported from a file or synced from a Garmin watch also keep every point instead of being cut to 2,000.

### Added

- **A FIT file with the GPS route.** A workout with a route can be saved or shared as a FIT that carries the route, the altitude and the distance covered, beside heart rate, speed and cadence: the whole recording in one file. The Export workout card now groups its formats under "With the GPS route" (GPX, KMZ, FIT) and "Without the GPS route" (TCX, CSV, FIT). The files without the route still hold no location at all.

### Changed

- **Imported routes keep every point.** A route file or a Garmin watch activity with more than 2,000 GPS points was cut to 2,000, evenly spaced, so a three-hour ride recorded every second kept a point about every five seconds. Every point is now kept, and the map, the splits and the route analysis use them all. A route too large for Health Connect to store in one record is still thinned until it fits. With elevation correction on, the climb of a long import is now computed from every point.

### Fixed

- **FIT and TCX exports with more than heart rate.** The workout export wrote only the heart-rate samples and the session totals, so FIT viewers showed nothing else. FIT and TCX now carry the speed and cadence samples the workout screen shows, and the FIT summary gives average and maximum speed and cadence. Every FIT also marks where the timer starts and stops, and the local time of the workout.

The app keeps the same package name and signing certificate, so this installs as a normal update.

Distribution flow:

- GitHub release with signed APK, signed debug APK, and signed Android App Bundle assets.
- Google Play update to follow, once 2.13.0 has cleared Play review.
